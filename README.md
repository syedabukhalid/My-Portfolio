Welcome to the repository for my official personal portfolio website! This responsive web application acts as a central hub displaying my technical skills, professional certifications, verified digital badges, client projects, and background in IT, Data Science, and Agentic AI.

👉 **Live Site:** [https://syedabukhalid.github.io/My-Portfolio/](https://syedabukhalid.github.io/My-Portfolio/)

---

## ✨ Features & Highlights

- **⚡ Modern Responsive Design:** Optimized for seamless viewing across mobile, tablet, and desktop viewports.
- **📜 Credential & Verification Hub:** Direct verification links to credentials from Oracle, Anthropic, Google, Cisco, HackerRank, and Hackviser.
- **🎖️ Interactive Badge Gallery:** Showcases official badges hosted on Accredible, Credly, and Google for Education.
- **📁 Portfolio & Client Projects Section:** Displays active client web development builds alongside personal software and data engineering projects.
- **🎨 Infinite Logo Carousel:** Smooth continuous ticker animation highlighting key tech stack tools and certifications.
- **📫 Integrated Contact Portal:** Quick access links and functional dynamic contact options for direct messaging.

---

## 🛠️ Tech Stack & Technologies

* **Frontend:** HTML5, CSS3, Modern JavaScript (ES6+)
* **Styling & Layout:** CSS Grid, Flexbox, Custom Media Queries, Smooth Scrolling
* **Fonts & Icons:** FontAwesome, Google Fonts
* **Hosting & Deployment:** GitHub Pages
